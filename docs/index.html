Static Go Core & Multi-Host Suite

cmd/agent-ooda • internal/* • plugins/*

agent-ooda separates host-agnostic Go packages from thin plugin adapters so multiple CLI hosts can share one battle-tested binary, quota store, lease mechanism, and verifier without code duplication.

Multi-Call Binary

One Static agent-ooda Executable

Built with CGO_ENABLED=0 and zero third-party packages. Inspects argv[0] to run as agent-ooda (dispatcher & CLI), agent-ooda-hud (status bar), or agent-ooda-hook (session skill recorder) with instant startup.

Shared Engine

Multi-Host Plugin & 3 Selectors

Core packages live under internal/{fleet,envelope,dispatch,verify,worktree,hud,cli,install} while plugins/agent-ooda ships the agy skill/hook suite, /lane, and 8 native /agents profiles (ooda-auto, conserve, deep, devin, grok, mcode, muse, mistral), synced with agent-ooda --select (-s).

Fail-Closed Supply

Zero-Go Verified Releases

GitHub Releases publish cross-compiled static binaries (linux/darwin, amd64/arm64) alongside SHA256SUMS. Hosts without Go verify the checksum fail-closed before installing.

The 8-Lane Fleet & Binary Guardrails

agent-ooda --status • --discover • --probe

Currently configured for the 6 agent CLIs (8 lanes) we actively subscribe to below. agent-ooda --status and agent-ooda --discover probe installed CLIs dynamically for active models, effort controls, UTC off-peak/peak-jam tariffs, and injectable skills. agent-ooda --probe runs minimal 1-token prompt canaries (skipping credits), while omitted --complexity and --skill infer automatically (opt out via --skill none or OODA_NO_AUTO_SKILL=1). Hard Binary Guardrails

Workers run with AGENT_OODA_DEPTH=1 & ROUTER_DEPTH=1 (or higher). The Go CLI blocks recursive dispatch, --probe, --cleanup, and quota mutations with exit 2 whenever depth >=1, and hard-rejects gemini* or orchestrator* models on any worker or review lane.

Cross-Model Diff Verification

agent-ooda --review .

No model family grades its own patch. agent-ooda --review excludes the authoring family automatically, tracks pre-task HeadRef state so worker commits never evade scope or review checks, renders untracked files as synthetic hunks, and fails closed on any [P0-3], UNKNOWN, or SKIPPED result.

≤ 8 KiB Working Tree

Native Repo Review

Invokes mcode exec review with --permission smart --max-steps 15 so the reviewer inspects surrounding context directly in the workspace.

> 8 KiB or Committed

Bounded Patch Audit

Streams a bounded patch audit prompt with --permission smart --prompt-mode coding --max-steps 25 against baseRef..working-tree or unborn HEAD.

Fail-Closed Backup

Off-Family Fallback

On cooldown, timeout (240s default), or UNKNOWN verdict, verification rotates across mcode → devin-fast → devin-pro → grok → mistral → muse → agy-opus.

Install

What the Installer Wires

The web installer clones or fast-forwards UberMetroid/agent-ooda into ${XDG_DATA_HOME:-~/.local/share}/agent-ooda and invokes ./install.sh. On hosts without Go 1.22+, install.sh downloads the matching static GitHub Release binary and verifies its SHA-256 checksum against SHA256SUMS before installing. It links ~/.gemini/config/plugins/agent-ooda, ~/.local/bin/agent-ooda, and ~/.gemini/antigravity-cli/statusline.py (migrating legacy v1.x shims safely), and wires ~/.gemini/antigravity-cli/settings.json idempotently.

Uninstall

Clean, Guarded Removal

./install.sh --uninstall removes only symlinks resolving into this repo and restores any archived previous statusLine. Quota state and backups/ stay intact unless you pass --purge, and the web installer refuses to purge a dirty or unpushed git checkout.

State Paths & House-Law Gates

Quota state (v9) and global stage pins persist under ${XDG_STATE_HOME:-~/.local/state}/agent-ooda/quota.json (override via AGENT_OODA_QUOTA_FILE); --local per-repo pins live out-of-git in workspaces/<id>.json. Live HUD markers and flock leases live in /tmp/agent-ooda-hud.
