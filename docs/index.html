statusLine Wiring

./install.sh links ~/.gemini/antigravity-cli/statusline.py to bin/ooda-hud and merges this block into ~/.gemini/antigravity-cli/settings.json. CRUISE

CONSERVE

RESERVE

Holds paid devin-fusion credits in reserve behind every renewable and free lane.

REGEN

Stage Routing Priority

Observe (recon): devin-fast → mcode → devin-pro
Act (default): Soonest-expiring capped lane → remaining capped → free lanes
Parallel stripe: agy-opus → muse → grok → mistral → devin-fast → devin-pro → mcode → devin-fusion
Fallback chain: agy-opus → muse → grok → mistral → devin-fusion → devin-fast → devin-pro → mcode

Recursion Guard

Every headless worker launches with ROUTER_DEPTH=1 (or higher). Installed rules in plugins/ooda/rules/AGENTS.md forbid spawned workers from invoking router, ooda, or dispatch.py recursively.

Cross-Model Diff Verification

router --review .

No model grades its own patch. router --review filters out the authoring family automatically, appends untracked files as synthetic hunks so new scripts never slip past git diff, and fails closed on any [P0-3] finding.

≤ 8 KiB Working Tree

Native Repo Review

Invokes mcode exec review with --permission smart --max-steps 15 so the reviewer can inspect surrounding files cleanly.

> 8 KiB or Committed

Lightweight Patch Mode

Streams a bounded single-pass patch prompt with --mode lightweight --permission off --max-steps 4 for fast, deterministic audits.

Fail-Closed Backup

Off-Family Fallback

On cooldown, non-zero exit, or an UNKNOWN verdict, verification rotates across mcode → devin-fast → devin-pro → grok → mistral → muse → agy-opus.

Install, Uninstall & House Laws

make all 
git clone https://github.com/UberMetroid/agy-skills.git
cd agy-skills
./install.sh          # links plugin, router/ooda CLI, HUD + statusLine
                      # (./install.sh --help for options)
# restart agy so the plugin + statusLine load
agy plugin list       # confirm "ooda" is enabled
router --status       # fleet tiers, resets & active locks
router --usage        # per-lane 5h cycle telemetry
router --recon "Map auth flow and callers"
router --review .     # cross-model diff gate
make all              # full House-Law + unit + dogfood suite

git pull && ./install.sh   # update
./install.sh --uninstall   # or ./uninstall.sh
./install.sh --uninstall --purge   # also drop quota state
Install

What install.sh Wires

Symlinks ~/.gemini/config/plugins/ooda, ~/.local/bin/ooda, ~/.local/bin/router, and ~/.gemini/antigravity-cli/statusline.py into plugins/ooda, then adds the statusLine block to ~/.gemini/antigravity-cli/settings.json (opt out with OODA_NO_STATUSLINE=1). It is idempotent. A malformed settings.json or skills.json stops it before anything changes, and displaced files are archived rather than deleted. At the end, a health report warns if ~/.local/bin is not on PATH or agy is missing, and lists which lane CLIs (agy devin muse grok vibe mcode) were found or missing.

Uninstall

Clean, Scoped Removal

./install.sh --uninstall removes only the symlinks that resolve into this repo, and lists foreign files it left in place. It drops the ooda statusLine, restoring your previous one if it was saved. The shared ~/.agents/skills entry stays in skills.json, and quota state and backups/ stay unless you add --purge. Running it twice is safe.

State Paths & House-Law Gates

Quota state persists under ${XDG_STATE_HOME:-~/.local/state}/ooda/quota.json (override with AGENT_QUOTA_FILE). Live HUD telemetry and flock slot markers live in /tmp/router-hud (override with ROUTER_HUD_DIR).
